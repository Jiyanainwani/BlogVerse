
# BlogVerse 📝

A full-stack blogging app where users can sign up, log in, and publish blogs with cover images.

## 🔧 Tech Stack

- **Frontend:** EJS, Bootstrap 5
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **Auth:** JWT, Cookies

## 📁 Structure

- `/views` – EJS templates (home, signin, signup, blog pages)
- `/routes` – User and blog routes
- `/models` – Mongoose schemas
- `/middlewares` – Auth middleware
- `/public` – Static assets
